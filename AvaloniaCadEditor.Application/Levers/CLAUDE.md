# Funcionalidade congelada: cotas que editam o código

Esta pasta é de uma funcionalidade **parada** (ARCHITECTURE.md §9.1). Se a tarefa não é sobre selecionar
uma cota e mudar o código por ela, pare aqui: não leia o resto, não use como exemplo e não estenda.

Se uma mudança em outro lugar quebrou a compilação daqui, ajuste o mínimo para compilar, sem refatorar. Se
um teste dela quebrou e o conserto não é imediato, marque com `[Fact(Skip = "...")]` e anote no plano.

Se a tarefa é sobre ela, comece pelo plano: `docs/planos/2026-11-10-cota-alavancas.md` ("Por que está
congelado" e "Mapa técnico").
